# 集成工業システム 仕様概要

## 基本サイクル
1. 採集（採鉱機） -> 倉庫
2. 加工（生産設備） -> 倉庫
3. 納品（拠点取引） -> 取引券獲得

## 設備特性
- **電力**: 協約核心を中心に供給。電力不足は生産停止を招く。
- **液体**: パイプで輸送。一部の設備（大型化学反応炉など）は液体と固体を同時に扱う。
- **副産物**: 赤銅精錬時の「汚水」など、処理が必要な副産物が発生する。

## 効率化のテクニック
- **PWM回路**: 分流器と合流器を使い、発電機への投入量を微調整することで、バッテリー消費を最適化する。
- **優先回路**: 汚水などの副産物を「利用」を優先し、余った分だけ「廃棄」するための仕組み。
- **倉庫上限**: アイテムごとに8000個（拡張可能）。放置時は多種類を少量ずつ生産するのが効率的。

## 地域別資源量 (Ver 1.2)
- **四号谷地全体**: 源石 560, 紫晶 200, 青鉄 1080
- **武陵全体**: 源石 480, 青鉄 90, 赤銅 180
