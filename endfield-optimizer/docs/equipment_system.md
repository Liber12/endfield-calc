## 精密加工（装備強化）
金装備のサブステータスを強化するシステムです。

### 必要素材
1. **強化対象の装備**
2. **素材装備**: 同じ部位の金装備。強化したい項目が初期値より高い必要がある。
3. **精密加工強化剤**: 地域取引のショップ（取引Lv2以上）で購入。

### 成功率と「高適合」
- **高適合**: 素材装備のステータスが強化元より高い場合。成功率が標準の約1.8倍になる（目安：26% vs 14%）。
- **失敗時**: 素材装備と強化剤は消費されるが、強化元の装備は失われない。
- **加工保証（天井）**: 一定回数失敗すると確定で成功する。

### 強化回数上限
- **胴体・腕**: 9回（3項目 x 3段階）
- **アクセサリー**: 6回（2項目 x 3段階）

## 強化優先度
| 優先度 | 項目 | 理由 |
| :--- | :--- | :--- |
| ★★★ | **固有能力** | チャージ効率、属性ダメージ等。他に盛る手段が少ない。 |
| ★★☆ | **メイン能力** | 知性、筋力等。キャラの基礎火力に直結する。 |
| ★☆☆ | **サブ能力** | 影響が小さいため後回しで良い。 |
