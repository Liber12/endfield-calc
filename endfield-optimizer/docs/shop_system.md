# 商品取引・ショップ仕様

## 商品の種類
- **定価商品**: 育成素材やスカウト券など。地域取引レベルを上げるとラインナップが増える。
- **時価商品**: 毎日価格が変動する。

## 主要な購入目標 (四号谷地)
- **通常スカウト券**: 各エリア合計で数枚。価格は1000〜50000と幅がある。
- **理性消費許可証**: 取引Lv4で解放。大量の取引券を要求されるが、スタミナ回復に直結する最重要アイテム。
- **武器・設計図**: 星5武器などがラインナップされる。

## 主要な購入目標 (武陵)
- **武陵刻印券**: キャラクター強化に必要。
- **滋養強壮の煎じ薬 / 野菜たっぷりチャーハン**: バフアイテム。

## 保管ボックスと容量
- 初期容量: 8000
- 各エリアの保管ボックスをレベルアップすることで、最大 **80000** まで拡張可能。
- 放置時間を稼ぐためには、容量の拡張が不可欠。

## 運用アドバイス
- 取引券の生産ペースを上回る速度で商品を生産できれば、常にショップを買い占めることが可能になる。
- 倉庫上限に達すると生産が止まるため、定期的に納品または処分が必要。
