# 拠点納品仕様・発展段階データ

提供されたWiki情報に基づく拠点の詳細データです。

## 地域区分
- **四号谷地 (Valley 4)**
  - 仮設居住地 (Refugee Camp)
  - 建設基地 (Infra-Station)
  - 再建管理本部 (Reconstruction HQ)
- **武陵 (Wuling)**
  - 天王原建設支援拠点
  - 心臓修復施設

## 特徴
- 各拠点には「地域特性」があり、特定のオペレーターを派遣することで発展値や取引券の獲得効率が上昇する。
- **武陵1.2**での高単価アイテム:
  - **緋銅部品**: 単価 48 (天王原 Lv3)
  - **中容量武陵バッテリー**: 単価 54 (天王原 Lv3, 心臓修復 Lv2)
  - **重息壌**: 単価 27 (心臓修復 Lv1)

## 注意事項
- 「芽針注射針」はデータ上「芽針注射剤」として扱う。
- 拠点の発展段階により、取引可能な商品が解放される。
- 取引券には生産効率があり、無限に納品できるわけではない（ソルバーの制約条件として重要）。
